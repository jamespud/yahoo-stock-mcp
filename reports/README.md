# Quant evidence

`quant-test-summary.json` is the common report index. `quant-test-summary.md` lists
actual acceptance command outcomes. `quant-reliability.json` / `.md` contain the
Python correctness results and source fingerprints. `quant-skills-sync.json` / `.md`
record standalone reference integrity, live catalogs and bundled file identities.
Real DSH transcripts/traces and their report have separate explicit run status.

Reports are regenerated by local commands described in `docs/QUANT_TESTING.md`.
Do not hand-edit a test failure into a pass or carry forward historical counts.
Logs and JUnit evidence explain failures and skips. Never commit provider secrets,
GUI profiles, private paths copied from user configuration, or downloaded market data.
